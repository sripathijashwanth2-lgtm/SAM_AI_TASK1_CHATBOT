# 🤖 Rule-Based AI Chatbot

## 📌 Project Overview

This project is a simple Rule-Based AI Chatbot developed as part of the SAM AI Technologies Internship – Task 1.

The chatbot uses predefined rules and pattern matching to understand user inputs and provide suitable responses.

## 🎯 Objective

The main objective of this project is to develop a basic chatbot that can:

- Accept user input
- Identify keywords or patterns
- Provide predefined responses
- Handle greetings and basic questions
- Handle unknown inputs
- Provide a simple interactive chatbot interface

## ✨ Features

- 👋 Greeting responses
- 🤖 Chatbot identity responses
- 😊 Conversation about chatbot status
- ❓ Help functionality
- 💡 Capability information
- 🙏 Thank-you responses
- 🏢 Internship-related response
- 👋 Goodbye functionality
- ⚠️ Unknown input handling
- 💬 Interactive Streamlit chat interface

## 🛠️ Technologies Used

- Python
- Streamlit
- Conditional Statements
- String Pattern Matching
